# Codex 脉动 2.9.0 改版说明

## build 291：Widget 同步修复

- 主面板展示内容变化后，WidgetKit 重载请求目标由 60 秒缩短为约 10 秒。
- 10 秒窗口内的连续变化合并为一次最早刷新，不会遗漏窗口内的最新快照。
- 只有 Widget 容器快照写入成功后才请求刷新，并在安装时注销同 Bundle ID 的历史构建注册。
- 安装后自动重载 WidgetKit 时间线服务，避免旧扩展进程继续显示安装前的缓存数值；桌面布局和用户数据保持不变。

## 第四优先级：版本更新检测

- 新增“自动检测版本更新”，默认开启。
- APP 启动后检查项目公开 GitHub Releases 的最新正式发布。
- 成功检查后 24 小时内不重复请求；网络失败时保留上次结果，6 小时后可自动重试。
- 设置页显示当前版本、线上版本、上次检查时间和发布说明。
- 支持“立即检查”和“查看并下载”；用户也可关闭自动检测。
- 菜单栏在有新版本时显示更新提示，并可直达对应发布页。
- 仪表盘菜单新增“检查版本更新…”入口。

## 比较与安全规则

- 使用语义化版本比较，正确处理 `2.10.0 > 2.9.0`。
- 稳定版高于同版本的预发布版，同时识别本地开发版高于线上版本的情况。
- 仅读取公开 GitHub Release 元数据，不使用 GitHub Token、账号或其他凭据。
- 不自动下载、不自动安装，更新页面只允许打开 HTTPS GitHub 地址。
- 远程检查失败不影响额度、Token、Radar、Widget 或可靠性自动化。

## 兼容性

- 系统要求：macOS 14 或更高版本。
- 未改变 Widget schema 和 iCloud 设备同步 schema。
- 现有额度历史、项目预算、可靠性事件和设置保持不变。
