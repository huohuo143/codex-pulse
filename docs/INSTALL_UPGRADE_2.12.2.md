Codex 脉动 2.12.2 安装与升级

从 https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.2 下载对应系统的文件，并使用随附 SHA-256 文件核对下载完整性。

Mac（Apple Silicon）

- 安装包：Codex-Pulse-v2.12.2-build2128-20261013-arm64.dmg；校验文件为同名 .dmg.sha256。
- 主程序要求 macOS 13 或更高，七款桌面小组件要求 macOS 14 或更高。本次仅提供 arm64 包，未提供 Intel 新包。
- 打开 DMG，运行“安装或更新（保留设置）.command”。安装器保留原应用与配置的回滚副本，完成后启动新版。
- 安装包采用 ad-hoc 签名，尚未公证。首次打开如被系统拦截，在“系统设置 → 隐私与安全性”中查看该应用的打开选项。
- 安装结束会显示备份位置。需要回退时，运行该备份中的“恢复上一版.command”；该操作会恢复备份时的配置，先保留升级后新增且需要继续使用的记录。
- DMG 内“本地版本；未发布到 GitHub”是构建时说明快照，当前发布状态以 Release 页面为准。

Windows（x64）

- 安装版：Codex脉动-Windows-2.12.2-x64-安装版.exe。
- 免安装版：Codex脉动-Windows-2.12.2-x64-免安装.exe。
- 校验文件：SHA256SUMS-2.12.2.txt。面向 Windows 10/11 x64，无需另行安装 Node.js。
- 已安装旧版时，从托盘退出 Codex 脉动，运行安装版并沿用原安装位置。保留原有应用数据目录，不删除设置或历史记录；免安装版适合直接运行。
- 本轮已验证从 2.12.1 升级到 2.12.2，安装前后设置文件一致；首次启动时窗口尺寸记录可能按当前显示环境调整，用户偏好保持。
- 升级前建议保留旧安装包并备份应用数据。当前数据目录沿用 %APPDATA%\Codex算力码表；部分旧安装使用 %APPDATA%\suanli-dashboard-windows，以实际存在的目录为准。
- 需要回退时，先退出应用并保存当前数据副本，再恢复旧程序及对应备份。不要用较早备份覆盖唯一一份升级后记录。
- 安装包没有商业 Authenticode 签名，Windows 可能显示未知发布者提示。

两端首次使用均需要本机已有可用的 Codex 登录与会话数据。首次历史解析可能需要等待；关闭主窗口与完全退出应用不同，Windows 完全退出请使用托盘中的“退出 Codex 脉动”。安装及验证不会要求用户上传账号凭据。
