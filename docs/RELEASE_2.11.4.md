# Codex 脉动 2.11.4 · Build 2125

悬浮额度环直接显示“距重置 X天 X小时”，更容易看清下一次额度重置还需要多久。

## 更新内容

- 按官方额度窗口的重置时刻计算天数与小时数，每分钟更新；不足一天时显示“0天 X小时”。
- 倒计时字体增大约三分之一并加粗，保留额度百分比与窗口标签；未取得重置时刻时显示待更新状态。
- 灵活额度支持按批次分别记录发放数量、到期日期和来源；推算日期明确标注，旧单笔记录继续保留。
- 安装器备份批次记录、设置和旧版应用，并提供回滚入口。

## 安装

本 Release 提供 Apple Silicon（arm64）DMG 与 SHA-256 校验文件。运行镜像中的“安装或更新（保留设置）.command”。主应用最低 macOS 13，桌面小组件最低 macOS 14。

安装包采用 ad-hoc 签名，尚未公证。个人到期记录保存在本机；发布包使用通用代码，测试使用虚构数据。
