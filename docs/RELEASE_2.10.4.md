# Codex 脉动 2.10.4 改版说明

## build 2107：Codex Radar 公共数据同步

- 将重置雷达主入口从已要求小程序登录的接口切换至 `codexradar.com` 公开只读源。
- 解析 Tibo 最新三条 Posts / Replies，显示原文、中文翻译、重置相关性、发布时间和 X 原帖链接。
- 在 App 内按透明固定规则估算 24 小时重置概率：事件状态作为基准，48 小时内 Tibo 动态按相关性加分，24–48 小时信号减半，结果上限 95%。
- 明确标记估算为非官方概率，并在界面列出每项计分依据。
- 同步“站长推荐”四类任务建议，以及 Sol、Terra、Luna、5.5 各 effort 的 IQ、平均费用和平均耗时。
- 保留 30 分钟自动同步、手动刷新和本次运行中的上次成功数据降级。
- 全程使用公开只读页面与 JSON，不读取 X Cookie、登录态、关注列表或其他凭据。

## 数据口径

重置百分数是 App 的启发式估算，不是 Tibo、OpenAI 或 Codex Radar 的官方概率。用户应通过界面中的 X 原帖链接核对官方措辞。
