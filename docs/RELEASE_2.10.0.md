# Codex 脉动 2.10.0 改版说明

## build 2102：30 天趋势、多设备堆叠与 Intel Mac 支持

- 趋势页新增“24 小时 / 按天”分段切换，默认继续显示原有最近 24 小时视图。
- 按天视图展示包含今天在内的最近 30 个自然日，固定日柱宽度并支持横向滚动。
- 首次切换到按天视图时自动定位到最新日期，仍可向左查看更早日期。
- 每日柱支持悬停查看日期、紧凑 Token 数、精确 Token 数和调用次数。
- 无调用日期补为 0，跨月和跨年日期保持连续。
- 24 小时和按天视图使用本机时间轴对齐 iCloud 中的设备快照，每台设备用稳定颜色堆叠显示。
- 图例和悬停气泡同时显示合计、各设备 Token、调用次数和快照更新时间。
- 显式 0 Token 与缺少 bucket 保持不同语义；缺失值不参与合计，并显示“暂无数据”。

## 数据与兼容性

- `TokenStats.daily` 从 14 个日桶扩展为 30 个日桶，按本机时区生成。
- iCloud 设备快照继续使用 schema 4；数组长度可变，因此新旧设备数据可以并行读取。
- schema 2/3/4 继续只读兼容；没有对应小时或按天序列的设备不生成虚假趋势。
- iCloud 不可用时自动回退为本机单设备趋势；未修改同步文件和 Widget schema。
- 高级分析继续只读取末尾 14 天，用于最近 7 天与前 7 天比较。
- Widget 快照继续输出 `daily14`，7 款 Widget 和 Widget schema 均未改变。
- 未改变额度、重置雷达、Full reset、项目预算、可靠性或本地设置数据。

## 验证

- 自动化测试覆盖 30 日上限、缺失日期补零、跨月、跨年、空数据和单日数据。
- 多设备测试覆盖 bucket key 对齐、堆叠合计、设备顺序独立性、稳定颜色索引、0/缺失值区分、可变长日序列和旧 schema。
- 回归测试确认高级分析仍使用 14 天，Widget 预览仍包含 14 个日点。
- 包体验证检查主 App 与 Widget 的版本号、build、Bundle ID、签名、沙盒 entitlement 和 WidgetKit 生命周期入口。
- 主 App 与 7 款 Widget 均已分别交叉编译并检查为 arm64 或 x86_64 Mach-O，两个架构使用独立 DMG。
