# Codex 脉动 2.12.41 / build 2169

在 2.12.31 的基础上增加 Tibo 动态读取、重置识别及桌面小组件改进。

- Tibo 优先读取 X 的公开动态，必要时补读线程并使用公开备用来源；纯媒体帖明确标注内容未读取。
- 重置相关的原帖和回复优先展示，区分预告、实际到账和普通讨论；关键词本身不构成重置证据。
- 北京时间 12:00–15:00 每 3 分钟；16:00–21:00 暂停；其余时段按固定表每 8–20 分钟。请求预算跨重启保存，跨小时按新时段计算。
- 主界面与小组件按实际检查节奏标记数据新鲜度，并提供官方额度历史小组件。

应用退出、休眠、X 登录状态、网络及页面覆盖范围可能影响读取。此发布仅提供 Apple Silicon Mac 安装包；Windows 与移动端使用各自版本。
