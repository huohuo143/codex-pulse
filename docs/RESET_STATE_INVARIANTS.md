# 重置状态的维护与验收

适用于本仓库 Mac 2.12.31（2159）主界面、悬浮框、小组件及随包共享的匿名移动数据契约。原生移动客户端的源码与安装包未包含在本次 Mac 发布中。

- 预告周期只由明确的预告原帖确定。分析中引用的普通产品更新、历史完成声明、分析时间和抓取时间，都不能推进预告周期。
- 本账号官方周额度实际恢复并开启新周周期时，关闭此前的预告。正常到期、百分比修正、缺少前后观察或过长缺测不能制造到账。
- 到账展示截至首次检测时间加 24 小时。刷新、重启、重新读取同步文件和同一轮稍后的公开确认不得延长；各独立采样端的首次检测时间可能不同。
- 真正更新的预告立即覆盖上一轮到账提示。到期后等待下一轮，失败或不确定分析不得复活旧一轮到账。
- 来源刷新状态与到账事实分开。断网不抹去已核实到账，也不能伪造“刷新正常”。未来完成时间不得提前启动倒计时。
- 旧缓存的错误预告时间由带版本的迁移校正；无法核验时保守保留边界，不能通过清空全部记录掩盖问题。
- 主界面、悬浮框和小组件读取同一状态结果。WidgetKit 时间线必须包含 24 小时结束边界。
- Mac 的重置状态变化立即写入移动同步文件；稳定数据保留一分钟合并。发布时刻不会替换额度、日志或公开源的真实采样时刻。

## 修改后的检查

运行 `script/verify_reset_behavior.sh all`。也可分别运行 `mac` 与 `shared`；后者验证移动共享数据契约。本仓库 Mac 常用构建入口已调用对应检查。原生移动客户端需在其独立测试工程中验收。

覆盖：普通更新夹杂在引用中、旧缓存迁移、账号到账、新一轮预告、刷新/重启、公开源失败、未来时间、24 小时前/到点/之后、同步限流。相关逻辑调整必须继续保留这些场景。

构建和安装成功之后，还要核对真实数据与实际显示。系统接受小组件时间线不等于桌面已经绘制；不能把逻辑测试或示例渲染写成真机界面验收。
