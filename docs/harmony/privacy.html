关于我们

Codex 脉动（Codex Pulse）由 huohuo143 独立维护，并非 OpenAI 官方客户端。联系邮箱：289614391@qq.com。本政策适用于鸿蒙邀请测试版。

账号授权与额度

你主动选择登录时，由系统浏览器打开 OpenAI 官方授权页。应用处理设备授权回执、访问与续期令牌、可能返回的身份令牌，以及令牌中的账号标识和有效期，用于授权、额度查询、续期与退出。应用不要求你将账号密码输入应用，也不发起模型对话。 设备直接连接 auth.openai.com 和 chatgpt.com；授权凭据与额度历史不上传至开发者另设的账号代管服务器。

本机历史与设置

应用仅记录服务返回的订阅类型、额度周期、已用比例、重置时间和实际采样时间，用于显示额度、趋势和重置状态。历史最多保留近 30 天、12,000 条，较早记录按十分钟保留真实端点与变化边界。主题、配色及刷新选项保存在本机。

公开动态与外部服务

同意本政策后，公开动态功能会从 codexradar.com 读取公开网页。网络连接向目标站点提供 IP 地址、请求时间和请求头等必要信息，不附带本应用保存的 OpenAI 授权凭据或账号额度。设置中的“公开动态联网”可停止后续公开源请求，已发出的请求可能完成。 你点击原帖时，浏览器可能访问 x.com；账号和原帖等服务可能涉及境外网络服务，具体由相关服务按其规则处理。

存储与安全

授权凭据通过系统 AssetStoreKit 保存，配置为设备解锁时可访问。额度历史与设置保存在应用本机存储。应用不将凭据写入历史、剪贴板、导出文件或应用日志；未接入广告和额外统计 SDK。系统与第三方服务自身的信息处理适用其政策。

复制、导出与反馈

仅在你点击复制或导出后，额度摘要或选定历史才会写入系统剪贴板，或保存到系统文件选择器中由你选定的位置。应用不读取剪贴板内容。 主动反馈时，邮箱服务会处理你发送的地址、描述和附件。请遮盖账号信息，不要发送密码、验证码、令牌或完整授权响应。反馈资料用于联系和排查，可通过支持邮箱申请删除。

权限与自主选择

本应用需要网络访问权限，不申请相机、麦克风、位置或通讯录权限；文件导出由系统选择器授权具体位置。你可以暂不同意并只查看说明，不会发起账号或公开动态请求。 同意后仍可不登录，关闭账号自动刷新或公开动态联网。设置中的“退出并撤回隐私同意”会清除本机授权与账号历史、停止后续联网，并返回说明页。

退出、删除与权利

退出登录会清除本机授权和本账号额度历史，并尝试撤销此次远端授权；若远端撤销未确认，应用会明确提示。公共日历和公开缓存可能继续保留。 已导出的文件与剪贴板副本请在系统中自行管理，退出应用不会自动删除副本。OpenAI 账号注销和第三方服务端数据请通过相应官方渠道办理，本应用不会代为注销账号。查看、导出、更正、删除或咨询，可联系 289614391@qq.com，我们会核实请求并按适用要求处理。

在线政策与支持页面

在线说明页面通过 GitHub Pages 托管。访问这些网页时，GitHub 会记录访问者 IP 地址用于安全，具体适用 GitHub 的隐私声明。应用内政策可离线查看；本应用不会因此把账号额度、授权凭据或本机历史上传到 GitHub。
