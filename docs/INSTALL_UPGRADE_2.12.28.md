# 安装与升级 2.12.28 / Build 2155

本轮安装包面向 Apple Silicon Mac；主程序需要 macOS 13+，桌面小组件需要 macOS 14+。

1. 下载 DMG 与同名 `.sha256`，在下载目录运行 `shasum -a 256 -c 文件名.dmg.sha256` 核对。
2. 打开 DMG，运行“安装或更新（保留设置）.command”。已有安装会保留设置、历史和小组件数据，并备份旧程序及提供恢复脚本；新用户也可拖到 Applications。
3. 这是 ad-hoc 签名、未公证包。若系统阻止首次打开，可在“系统设置 → 隐私与安全性”确认自己下载的应用；无需关闭系统安全功能。
4. 在本机 Codex 桌面版或 CLI 登录自己的账号。打开脉动“设置 → 本机账号、模型与 Tibo 来源”进行检测。
5. Tibo 默认使用公开源，无需 X 登录。新用户默认不开启模型分析；需要判断预告时，选择本机可用模型并启用，分析会消耗自己账号的额度。API Key 登录按 API 计费。
6. 可选切换至 X 官网来源并打开 X 窗口，按页面要求自行登录，完成后关闭窗口，等下一轮检查。来源切换不绕过十分钟间隔；X 页面未加载、受限或无法识别时会显示错误，可切回公开源。

网页版 ChatGPT 的登录不能替代本机 Codex 登录。缺少权限的额度或 Full reset 数据显示不可用；本地 Token 只统计本机可读记录，不是整个账号网页端的全部用量。

桌面右键选择“编辑小组件”可添加 Codex 脉动小组件。预告红色、等待绿色、落实白色；若被 macOS 显示成灰色，请检查“桌面与程序坞”中的小组件样式与调暗设置。WidgetKit 的实际刷新时刻由系统调度，可能稍晚于主程序。

X 登录态仅存于本机 WebKit，不读取其他浏览器的 Cookie。安装包不含作者的账号、登录态、历史、API Key 或使用者个人设置。卸载程序时，不要删除应用支持目录，除非希望同时清除自己的历史与设置。
