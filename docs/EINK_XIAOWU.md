# 小悟墨水屏看板

Mac 版“设置 → 墨水屏 · 小悟云”将算力总览、Tibo 重置预告、最近 7 天官方额度历史合成一页。Mac 负责采集和绘图，小悟云保存图片，屏幕通过自身 Wi-Fi 获取画面。保留官方固件，新增个人设备专属的“Codex 脉动”模式。

## 首次连接

1. 选择屏幕实际分辨率和色彩。可先在本地切换示例、当前账号预览，或导出 PNG。
2. 点击“登录小悟”，在 `https://xiaowuai.vip` 官方窗口自行登录、绑定设备。应用使用 WebKit 管理本机登录状态，不提取其他浏览器凭据。
3. 回到设置，点击“读取绑定设备”并选择目标。设备或尺寸改变后，需要重新验证示例。
4. 点击“上传示例看板”，然后“读取云端预览”。只有图片上传和云端布局预览成功，才更新该设备的专属模式。
5. 打开“小悟设备配置”，将新出现的“Codex 脉动”模式单独选中或加入轮播。应用不会自动改写原有模式、刷新间隔或轮播顺序。
6. 在墨水屏上实际看到示例后，点击“我已在墨水屏看到示例”。这是使用者的实机确认，不由文件生成或云端预览替代。
7. 等待本机账号数据后，点击“立即同步真实看板”或开启每 10 分钟同步。

如果没有绑定设备，先在小悟官网完成绑定；不用在聊天中填写账号密码或令牌。模式采用安装实例与设备隔离的标识，同一 Mac 对同一设备更新已有模式，不重复新增。更换电脑或应用偏好存储会产生新的模式标识。

## 时间和数据含义

- 图片右上角为生成时间，底部为额度、用量、预告各自的数据时间，均为北京时间。周期倒计时、到账展示剩余时间均截至图片生成时刻，显示到分钟。
- 每 10 分钟上传一次；重置预告或到账状态变化时提前上传。设备显示仍受唤醒时间和轮播周期影响。
- Mac 休眠或退出后停止采集和上传，云端保留末次快照；图片中的倒计时不会独立走动。小悟云天气、AI 等其他模式按其原有规则运行。
- 缺失或过期的数据不填成 0。真实的 0% 和 0 次仍显示为零。到账展示沿用原先确认的 24 小时边界，新预告优先。
- 额度历史只覆盖当前账号已记录的样本；重置、额度上调或超过 90 分钟缺测会断线，不插值补齐。曲线末次采样值可与当前有效额度不同。
- Codex 账号切换会暂停自动同步，需检查当前预览后重新开启；此前云端画面保留原数据时间。设备和尺寸改变则清除示例验证状态。

## 云端内容与失败处理

上传内容仅为生成的黑白图片及其尺寸、专属模式定义和目标设备信息。图片只含额度百分比、24h Token 汇总、重置状态与期限、Full reset 次数、7 天额度曲线和数据时间。任意模型摘要、帖子原文、项目名称、路径、会话内容和 Codex 账号标识不会进入看板数据投影。

上游上传接口用随机 URL 读取图片，没有设备级读图鉴权，不能视为私密存储。该 URL 不显示或写入应用日志；模式不发布到模式广场。云端保留和清理图片的期限由服务方决定，应用不声称删除旧链接。

上传流程：`POST /api/uploads` → `POST /api/modes/custom/preview` 验证尺寸与 PNG → `POST /api/modes/custom` 保存设备模式。另通过 `GET /api/preview` 读取保存后的云端预览。请求在官方页面同源执行，登录状态由 WebKit 自动附带，不导出 Cookie。

网络失败保留上一次模式，按 30 秒到 10 分钟退避；401 登录失效暂停自动同步。接口、权限或返回格式不兼容时停止自动同步，保留本地预览并显示原因，不自动刷固件、部署代理或更改其他模式。上游服务在提交后的内部故障不受客户端控制；此时应先重新读取云端预览确认实际状态。

## 尺寸与验证边界

| 类型 | 当前支持范围 | 验证要求 |
|---|---|---|
| 400 × 300 | 原生像素布局、黑白 PNG、云端页眉页脚预留 | 本地渲染与模拟接口测试；云端和实机另验 |
| 648 × 480 | 同上，重新计算布局 | 同上 |
| 800 × 480 | 同上，避免按宽缩放后越过页脚 | 同上 |
| 自定义 | 宽 400–1600、高 300–1200；黑白、三色、四色 | 逐分辨率、逐机型验证 |
| 六色 / E6 | 仅本地黑白预览 | 上游接口当前仅支持 2–4 色参数，暂不上传 |
| 7/10 英寸、双屏、NFC/蓝牙 | 未宣称接入兼容 | 需确认固件协议及联网方式，不能由尺寸推断 |

本地预览的“小悟页眉 / 页脚”为占位区域，实际天气、电量、日期由小悟云绘制。此版本不内置新屏幕驱动、不升级固件，也不把本地测试计作实机验收。

## 开发验证

测试名称包含 `EInk`，覆盖数据白名单、缺失与真实零值、有效期、重置状态优先级、曲线分段、同步节流与退避、图片尺寸和黑白像素、提交顺序、登录失效、账号切换与示例验证门槛。

设置 `CODEX_PULSE_EINK_RENDER_DIR` 后运行 `swift test --filter EInk`，将生成三种尺寸的示例 / 空数据画面及带预留区域的设备预览。所有测试使用模拟云端服务，不访问个人小悟账号。
