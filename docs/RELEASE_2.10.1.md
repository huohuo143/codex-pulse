# Codex 脉动 2.10.1 改版说明

## build 2103：可选的 5 小时额度

- “设置 → 悬浮框 → 悬浮框显示信息”新增“5 小时额度”选项。
- 5 小时额度默认关闭，不改变升级用户原有的悬浮框布局。
- 开启后可在额度环、圆形、方形、胶囊、横条和徽章等全部八种悬浮框样式中显示。
- 5 小时与 7 天额度按官方 `window_minutes` 时长识别，不依赖 `primary` 或 `secondary` 的固定位置。
- 当官方数据暂未提供 5 小时窗口时显示 `--`，不会用 7 天额度或本地 Token 推算。

## 兼容性

- 保留原有 7 天额度、Token、重置雷达、Full reset、预测、提醒和 Widget 行为。
- 已保存的悬浮框选择继续生效；只有用户主动勾选后才显示 5 小时额度。
- 正式版本为 2.10.1 / build 2103。

## 验证重点

- 覆盖 5 小时窗口位于 `primary`、仅有 5 小时窗口以及 5 小时与 7 天窗口并存的情况。
- 覆盖新增选项的默认关闭、保存与恢复。
- 检查全部八种悬浮框样式在单独选择、与 7 天额度组合以及与 Token 组合时的布局。
