# Codex 脉动 2.6.0 改版说明

## 本次重点

- 新增官方 7 天额度历史快照，最多保留 30 天，只保存额度百分点、采样时间和官方重置时间。
- 新增稳健额度预测，综合最近 6、24、72 小时速度，展示耗尽区间、均衡日上限、重置时预计余额、风险和置信度。
- 概览页在原有额度总览下增加“额度节奏与预测”卡片，不调整重置雷达和 Full reset 顺序。
- 新增 macOS 菜单栏轻量面板；关闭主窗口后 App 继续运行，保留额度刷新与预警。
- 新增用户主动开启的系统通知，支持标准、提前和仅紧急三套阈值。

## 预测边界

- 只使用官方 7 天额度窗口的百分点变化，不用本地 Token 换算官方额度。
- 跨官方重置或余额明显回升时自动开始新的预测分段。
- 少于 4 个样本、覆盖不足 2 小时、累计变化不足 0.5 个百分点、数据超过 30 分钟未更新或缺少官方重置时间时显示“学习中”。
- 预测是本地趋势参考，不是 OpenAI 官方额度承诺。

## 隐私与兼容

- 额度历史不包含对话、项目路径、账户 ID、凭据或 API Key。
- 原生通知默认关闭，只有用户主动开启后才申请系统权限。
- Widget、iCloud 设备同步、Token 统计、Full reset 和重置雷达 schema 均未改变。

## 安装边界

- 系统要求：macOS 14 或更高版本。
- 架构：Apple Silicon arm64。
- 签名：ad-hoc。
- 公证：未公证，首次打开可能出现 Gatekeeper 提示。
