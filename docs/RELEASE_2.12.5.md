# Codex 脉动 2.12.5 · Build 2131

改进灵活额度到期记录的保存、数据保护与恢复，包含 2.12.4 的保存可靠性修复。

- 无法读取、损坏或不支持的记录会显示原因并停止保存，避免空列表覆盖原文件。
- 每次保存前重新校验当前文件，先保留上一份有效记录；备份失败时保持原记录。
- 提供“重新读取”“恢复上次有效记录”和“打开记录文件夹”；恢复前保留损坏原件。
- 恢复旧备份和保存失败后保留未保存输入、记录身份、原数量、金额和通知日期。
- 保存期间显示进度并阻止重复提交；账户变化时保留草稿，写入仍归属提交时的账户。
- 严格校验数量千位分组；编辑时保留原数量精度，日期选择遵循记录时区。
- 每日备份和安装备份包含分笔额度记录、上一份有效记录与损坏原件。

本次提供 Apple Silicon（arm64）Mac DMG。主应用最低 macOS 13，小组件最低 macOS 14。安装包为 ad-hoc 签名，尚未公证。本次没有新 Intel 或 Windows 安装包；Windows 公开安装包继续使用 [v2.12.2](https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.2)。

运行镜像内“安装或更新（保留设置）.command”升级。镜像内“本地版本／未发布”的说明是构建时的快照，发布状态以 GitHub Release 页面为准。安装与已知服务登记问题见 [安装说明](INSTALL_UPGRADE_2.12.5.md)，验证范围见 [验证说明](VALIDATION_2.12.5.md)。
