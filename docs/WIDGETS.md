# Codex 脉动 macOS 桌面小组件

`Codex 脉动 2.12.25` 继续提供 7 款 WidgetKit 小组件。所有组件读取主 App 原子写入的同一份聚合快照，数据口径与悬浮框一致；雷达快照另外携带本次检查、Tibo 源、有效证据、模型分析时间以及正常/缓存/过期状态。总览和额度组件可显示 7 天外环与橙色 5 小时内环；小组件的 5 小时内环默认关闭，可在主 App 设置中独立开启。

## 组件组

| 小组件 | 支持尺寸 | 主要信息 |
| --- | --- | --- |
| Codex 算力总览 | 中、大 | 7 天额度外环、可选 5 小时内环、滚动 24h、重置预告和北京时间期限、Full reset；大尺寸增加 Token 汇总、费用和 24h 趋势 |
| Codex 额度 | 小、中 | 7 天额度外环、可选 5 小时内环、已用比例、重置倒计时 |
| Codex 重置雷达 | 小、中 | 重置预告、醒目北京时间截止时间、到账 24 小时倒计时与刷新状态 |
| Full reset 权益 | 小、中 | 可用次数和最多 3 次到期时间，只读展示 |
| Token 汇总 | 小、中 | 滚动 24h、今日、近 7 天、本月 Token 与 API 等价预估 |
| Token 趋势 | 中、大 | 24 小时逐时柱状图；大尺寸增加最近 14 天趋势 |
| 项目与用途 | 中、大 | 今日项目 Top 3、本月用途 Top 3 |

## 推荐组合

- 信息完整：中号“Codex 算力总览” + 中号“Token 趋势”。
- 重置关注：小号“Codex 重置雷达” + 小号“Full reset 权益”。
- 极简桌面：仅保留小号“Codex 额度”。

## 与悬浮框的关系

- “设置 → 悬浮框 → 启用悬浮框”可以随时关闭或恢复悬浮框；关闭后由 Codex 自动唤起时 App 静默后台运行，手动打开时仍显示普通主窗口，已添加的桌面小组件继续保留。
- 悬浮框中的 7 天额度、5 小时额度、滚动 24h Token、重置雷达与 Full reset 权益可以分别勾选，至少保留一项；同时开启两种额度时显示为同心环。
- “设置 → macOS 桌面小组件 → 显示 5 小时额度内环”独立控制总览和额度小组件，默认关闭。
- 桌面小组件和悬浮框共享同一数据口径，但显示开关相互独立：悬浮框是否显示 5 小时额度不会改变小组件设置。

## 数据与刷新

- 主 App 继续按设置的 5/10/30 秒频率读取本地额度；完整 Token 汇总按现有 5 分钟节流执行。
- 重置雷达每 10 分钟检查公开源并调用 GPT-6 Astra / High；手动刷新和重启不绕过检查间隔。
- 主 App 将聚合快照原子写入 Widget 扩展自身容器；明确期限、到账展示结束时间和预告状态随同发布。
- 首次发布立即请求重载，其后将密集变化合并到最早可重载时刻，间隔至少60秒；系统最终重绘可能再有延迟。本次真实桌面验证观察到模型完成后约58秒显示新期限。
- WidgetKit 请求在5分钟后重新读快照；缺少有效数据时请求在1分钟后重试。上述时刻是系统调度请求，并非保证实时刷新。
- 预先安排有效期和到账倒计时结束节点，旧数据过期后明确显示等待刷新；主程序未运行时不会把旧快照当成最新结果。
- 新预告立即替代已到账状态和24小时倒计时；确认到账的起点固定，不随刷新或重启延后。全彩模式强调预告色块，单色模式保持文字可读。

## 隐私与沙盒

快照不包含会话内容、源文件路径、项目路径、账户凭据、API Key、完整账户 ID 或 Full reset 兑换 ID。Widget 扩展只启用标准 App Sandbox，不申请临时跨容器权限；主 App 负责将脱敏快照发布到扩展自己的容器。若后续改为 Developer ID 或 Mac App Store 分发，可迁移到正式 App Group container。

## 添加方法

1. 安装并打开一次“Codex 脉动”，等待面板出现数据。
2. 在 macOS 桌面空白处右键，选择“编辑小组件”。
3. 搜索“Codex 脉动”。
4. 选择所需组件与尺寸。

## 构建结构

## 2.12.26 本账号实际重置确认

官方额度历史同时出现额度恢复与周周期重新开始时，APP、悬浮框、雷达及概览小组件统一切换为“已完成重置”，以首次检测到账时刻为固定起点展示24小时倒计时。稍后的刷新、重启或公开完成确认不会重新计时。新预告优先覆盖，到期等待下一轮。公开动态或模型失败时，保留已确认的到账事实，同时如实显示刷新状态。此确认仅代表当前账号。
