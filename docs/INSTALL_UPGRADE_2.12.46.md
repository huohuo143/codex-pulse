# Codex 脉动 2.12.46 安装与升级

适用于 Apple Silicon Mac，安装工具需要 macOS 14 或更高版本。应用为 ad-hoc 签名，未经过 Apple 公证；初次打开若被系统阻止，请确认下载来源后按 Finder 或系统设置提示允许打开。

1. 下载并打开本发布页的 `.dmg` 文件，双击“安装或更新.command”。
2. 阅读提示，输入 `y` 并回车。安装器会检查版本及侧栏功能兼容性，保留现有设置和历史，并备份已有应用与可恢复的配置。
3. 若检测到可识别的旧独立侧栏 App，安装成功后会将其和相关启动项移入废纸篓；侧栏由脉动接管。
4. 在脉动“设置 → Codex 侧栏状态”调整显示项；在“设置 → OpenAI API 用量”自行连接有权限的密钥，或根据账单手动确认赠额与到期时间。

请使用包内安装工具更新：直接拖拽 App 覆盖不能执行侧栏功能兼容检查。账单时间不清楚时保持待确认；用户凭据不包含在安装包内。
