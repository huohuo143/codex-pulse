# Codex 脉动 2.12.0

本轮增加官方额度历史与更完整的用量导出，并修复提醒发送失败后的记账和重试。

## 官方额度历史

在主窗口「趋势」页查看当前账户本机采集的官方 7 天剩余额度，支持最近 24 小时、7 天、30 天。可悬停查看采样时刻、剩余百分比及当时的官方重置时间，也可点击「导出样本」保存所选范围的 CSV。

历史来源为原有额度采样，不按 Token 换算，不补造 App 关闭期间的数据。周期变化、额度上调或相邻采样间隔超过 90 分钟时断线。没有样本时显示空状态；账户切换立即清空旧账户的历史与预测，等待新账户载入。图表对长历史保留分段端点与极值进行显示抽样，悬停与 CSV 仍使用全部有效采样。

## 用量 CSV

保留顶栏的导出入口，新增本机逐日用量、设备快照汇总和设备逐日数据。小时记录使用完整 UTC 日期时间，避免跨日或跨年记录混淆。无法识别的原始小时键予以保留，时间留空。设备日统计保留源设备的日历日期，因未记录源时区而不推算时区。

本机统计与设备快照分区展示，设备区可能包含本机，不叠加回本机总量。相同设备 ID 只使用最新快照。保留价格覆盖率、未计价模型和 API 等价金额说明。模型、项目、设备等文本值按文本安全导出，避免表格软件将其解释为公式。

## 提醒可靠性

只有 macOS 通知系统接受请求后才标记已提醒。失败保留重试机会，并至少等待 60 秒；重叠刷新不会产生并发发送批次。部分成功只记录成功项。再次进入高风险后的失败通知也可重试，成功后仍遵守去重和冷却规则。账户切换取消旧发送批次，旧异步结果不会污染新账户账本。

提醒默认仍关闭，开启方式不变。系统接受请求不等于用户已看到横幅，横幅仍受 macOS 通知设置和专注模式影响。

## 数据与兼容性

主应用最低 macOS 13；桌面小组件最低 macOS 14。本轮不改变小组件数据格式、iCloud 同步格式或用户设置。额度历史 CSV 不包含账户标识、项目路径或对话正文；用量 CSV 保留原有模型和项目名称，并新增设备名称及设备 ID。
