# Codex 脉动 2.10.9 改版说明

## Build 2116：保留跨重置周期的次日庆祝信号

- 修复 Tibo 同一条状态既确认本轮按钮已按下，又将另一场庆祝延期至明天时，新周期信号被重置边界一并清空的问题。
- 当这类双重语义 Post 与已完成重置共用同一时间锚点时，App 会关闭旧周期，同时把延期至次日的部分保留到新周期。
- 新增“跨周期次日庆祝强信号”类别：基础 70%，独立 Post 权重 5%，本地 24 小时估算为 75%（高概率）。
- 普通的本轮重置完成帖仍会正常清空；后续真正完成下一次重置时，本次延期信号也会被清理，不会永久累积。
- BANKED reset 仍与全局硬重置分开判定。

风险边界：75% 是 App 基于 Tibo 公开措辞的保守本地估算，不是 Tibo、OpenAI 或 Codex Radar 的官方承诺。“庆祝”仍可能是 BANKED reset、提额或产品发布。
