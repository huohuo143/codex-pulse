# Codex 脉动 2.11.3 · Build 2121

本版修复重置雷达遗漏最新 Tibo 动态，以及短暂断连后恢复同步不及时的问题，包含本机 2.11.2 的动态显示修复。

## 修复内容

- 显示公开源收录的最新 Posts / Replies 和挑战进展，按实际发布时间排序，可展开查看全部动态；页面摘要明确标注，不补写英文原文，不计作重置承诺。
- 短暂连接故障和暂时性服务器错误在同次同步中最多尝试 3 次；主请求总时限 30 秒，附属来源独立并行读取且最多 6 秒。
- 网络恢复时立即重连；连续失败依次退避 1、5、15、30 分钟。自动刷新、手动刷新和重启恢复遵守服务器 Retry-After 等待时间。
- 首次无数据显示“等待数据”；缓存与失败原因明确显示。超过 90 分钟未成功同步时停止展示旧概率，APP 与小组件口径一致。
- 兼容网页属性顺序、额外 class 和单/双引号变化，保留作者、Post ID、链接与动态完整性校验。
- 本机保存最新动态、实际成功时间、连续失败次数、等待期限和最近 48 次同步结果，用于恢复与排查。

## 验证

- 81 项不同相关检查通过，包括短暂断连重试、超时取消、APP 网络恢复流程、限流等待、重启缓存恢复、概率过期与小组件状态。
- 本机安装 2.11.3 后完成原生界面和手动刷新验证；随后 9 个连续的 30 分钟自动同步周期均成功，最新动态继续更新。
- 主应用与 7 款小组件重新构建并验证签名、arm64 架构、扩展入口、图标与标准沙盒；APP 与小组件容器快照一致。
- 断网恢复与限流通过隔离场景验证；本机验证不替代其他 macOS 版本和硬件的实机测试。

## 安装

下载本 Release 的 Apple Silicon（arm64）DMG，运行其中“安装或更新（保留设置）.command”。安装器保留上一版程序和本机设置，并生成回滚入口。

主应用最低 macOS 13，小组件最低 macOS 14。安装包采用 ad-hoc 签名，尚未公证。本次没有发布 Intel 或 Windows 新包；Windows 请继续使用 v2.11.0 Release。

重置概率由本地规则估算，尚未经统计校准；当前没有有效硬重置证据时的 0% 不代表真实发生概率为零。公开源覆盖范围与可访问性仍影响动态收录。
