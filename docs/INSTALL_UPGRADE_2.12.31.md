# 安装或升级 Codex 脉动 2.12.31

1. 下载本次 arm64 DMG 与对应 SHA-256 文件，核对校验值。
2. 打开 DMG，运行“安装或更新（保留设置）.command”。它会安装至当前用户的 Applications 文件夹，退出并核对旧应用和扩展，保留应用与本地记录备份。
3. 安装完成后查看主界面、悬浮框和已有小组件。系统接受时间线后，桌面实际绘制可能稍晚；无需清空小组件缓存或重新布置桌面。

安装器会输出备份位置及“恢复上一版.command”。遇到退出或验证失败时，应先查看输出并保留备份，不在旧进程仍运行时手工覆盖应用。

主应用要求 macOS 13+，桌面小组件要求 macOS 14+。本包为 Apple Silicon arm64、ad-hoc 签名、未公证版本，系统可能提示无法验证开发者。是否允许打开请由使用者自行判断；不要关闭系统整体安全保护。

安装包不含维护者账号或配置；使用安装者本机 Codex 登录和已有记录。模型分析为可选项，启用后消耗使用者自己的额度。移动同步为可选的匿名聚合文件导出；同一 Apple 账号及目录授权要求以界面说明为准。
