# Codex 脉动 2.5.3 改版说明

## 本次重点

- “趋势 → 最近24小时”柱状图新增即时悬停气泡，显示本机时区的具体小时。
- Tooltip 主读数在 1M 至不足 1 亿时使用 `M`，达到 1 亿后使用“亿”。
- 紧凑读数最多保留两位小数并自动移除末尾 0；下方同时保留带千位分隔符的精确 Token 整数。

## 交互优化

- 每个小时列提供完整高度的悬停区域，0 Token 或很低的柱也能稳定定位。
- 当前小时柱会高亮；首尾小时的气泡位置自动限制在图表范围内。
- 保留 macOS 系统帮助提示和无障碍读数，键盘辅助功能仍可读取具体小时和精确 Token。

## 数据边界

- 时间精度保持为小时，不推断分钟级调用时间。
- 小时桶、滚动 24 小时、费用估算、iCloud 同步和 Widget 快照格式均未改变。
- 滚动 24 小时总值仍按精确时间戳计算，因此可能与 24 个自然小时柱的简单求和略有差异。

## 安装边界

- 系统要求：macOS 14 或更高版本。
- 架构：Apple Silicon arm64。
- 签名：ad-hoc。
- 公证：未公证，首次打开可能出现 Gatekeeper 提示。
- 打包过程不会覆盖当前已安装的 2.5.2；只有用户主动运行 DMG 内安装脚本时才会替换同名 App。

安装包：

```text
Codex-Pulse-v2.5.3-20260716-arm64.dmg
Codex-Pulse-v2.5.3-20260716-arm64.dmg.sha256
```
