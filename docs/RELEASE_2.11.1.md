# Codex 脉动 2.11.1 · Build 2119

本版修复新版 Codex/ChatGPT 更新后，官方额度与灵活额度显示为“--”的问题。

## 修复内容

- 兼容新版 `codex-cli/CodexCLI.app/Contents/MacOS/codex` 程序位置，同时保留旧版布局与 PATH 查找。
- 支持 ChatGPT.app、Codex.app，以及系统和用户 Applications 安装目录。
- 修复“随 Codex 启动”服务对 ChatGPT.app 新进程名的识别；正常停止服务时清理启动锁。
- 保留现有偏好、用量历史与 7 款桌面小组件。

## 验证

- 27 项相关回归测试通过；额外完成 1 项真实官方接口冷启动验证。
- 正式安装后验证官方额度、灵活额度和手动刷新；完整退出后由自动启动服务重新拉起，并再次成功读取官方数据。
- 主应用和小组件签名、arm64 架构及 7 种小组件配置检查通过；主应用与小组件快照一致。

## 安装

下载 DMG 后运行“安装或更新（保留设置）.command”。安装器会保留旧版应用和设置，并生成回滚脚本。

本次发布提供 Apple Silicon（arm64）安装包。主应用最低 macOS 13，小组件最低 macOS 14；本次实际验收在 Apple Silicon Mac 上完成。本包采用 ad-hoc 签名，尚未公证。安装包内复用已验证的 2.11.0 小组件可执行逻辑，仅更新对应版本信息并重新签名。

本版是 macOS 兼容性修复；Windows 安装包仍请使用 v2.11.0 Release。
