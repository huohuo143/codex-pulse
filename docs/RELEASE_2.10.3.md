# Codex 脉动 2.10.3 改版说明

## build 2106：主窗口概览双额度环

- 主窗口“概览”使用 7 天外环与橙色 5 小时内环。
- 双环中心同时标注两种官方窗口的剩余比例。
- 概览卡片分别显示 7 天和 5 小时官方重置时间。
- “设置 → 悬浮框显示信息 → 5 小时额度”同时控制悬浮框和主窗口概览，取消勾选后概览恢复为单一 7 天额度环。
- 桌面小组件继续保留独立的 5 小时显示偏好。

## 数据边界

- 两种额度均来自 Codex 官方窗口，不使用本地 Token 消耗反推。
- 官方暂未返回 5 小时窗口时显示 `--` 和“暂无官方窗口数据”。
- 本次更新不改变会话日志、项目统计或 Widget 快照的隐私边界。
