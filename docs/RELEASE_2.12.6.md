# Codex 脉动 2.12.6 / Build 2132

主窗口新增“重置日历”，也可从“仪表盘 → 打开重置日历”或按 ⌘4 进入。

- 月历固定使用北京时间，周一至周日排列，可切换月份和返回本月。
- 硬重置和重置卡分别标记、分别统计，支持类型筛选和同日多事件详情。
- 详情保留官方确认或站长根据社区反馈确认的来源区别；预告和完成确认合并为同一事件。
- 实际发生时间、原帖发布时间、确认帖发布时间分开显示。只有确认日期的记录明确注明实际发生时间未公布。
- 公开来源只有月度总数的记录单独展示，不分配到具体日期；空白日期不表示一定未发生重置。
- 日历沿用每 30 分钟同步和手动刷新，独立保存历史；断网继续显示已收录记录，解析失败不影响现有重置雷达。
- 日历缓存纳入每日备份和安装备份；保留既有设置与数据。

数据来自 Codex Radar 的公开页面与公开完成记录，首次覆盖范围取决于来源可提供的日期记录，不代表完整历史事件库。重置卡发放与直接重置分别计数；不自动操作账户权益。
