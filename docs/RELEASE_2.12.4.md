# Codex 脉动 2.12.4 · Build 2130

以下改进已包含在 2.12.5 发布包中：

- 新记录保存后保持选中，可继续编辑；保存期间显示进度并阻止重复提交。
- 保存失败或账户变化时保留草稿，记录仍归属提交时的账户。
- 数量输入校验千位分组与正数范围；编辑时保留原数量精度。
- 到期日期选择遵循记录本身的时区。
- 每日备份纳入分笔额度和旧版历史记录，并校验备份完整性。
- 补齐计时器的 Combine 导入，修正雷达超时测试的调度假设。

实际发布与验证范围见 [2.12.5 更新说明](RELEASE_2.12.5.md) 和 [2.12.5 验证说明](VALIDATION_2.12.5.md)。
