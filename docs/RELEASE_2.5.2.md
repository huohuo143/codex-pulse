# Codex 脉动 2.5.2 改版说明

## 本次重点

- App 正式更名为“Codex 脉动”，启用额度环与雷达主题的原生多尺寸 macOS Logo。
- 新增 7 款 WidgetKit 桌面小组件：总览、7 天额度、Codex 重置雷达、Full reset 权益、Token 汇总、Token 趋势、项目与用途。
- 新增“启用悬浮框”总开关；关闭后由 Codex 自动唤起时静默后台运行，手动打开 App 仍显示普通主窗口。
- 悬浮框可分别选择 7 天额度、滚动 24h Token、重置雷达和 Full reset 权益，八种样式会自动适配内容与尺寸。
- 新增“跟随系统、白天、夜晚”三种背景模式，主窗口、设置页和悬浮框均可自动或手动切换。

## 桌面小组件

- 中号和大号“Codex 算力总览”复刻悬浮框的核心信息。
- 其余小组件按额度、重置、权益、Token、趋势和项目用途拆分，可自由组合。
- 主 App 将脱敏聚合快照发布到 Widget 扩展自己的沙盒容器。
- 快照不包含会话内容、凭据、项目路径、API Key、完整账户 ID 或权益兑换 ID。
- 主 App 最多每分钟通知 WidgetKit 重载；实际刷新时间仍由 macOS 组件预算决定。

## 修复与优化

- 修复 2.5.1 中扩展入口按普通 SwiftPM 可执行程序链接、WidgetKit 无法取得组件清单的问题。
- Widget 改用原生 App Extension 生命周期，系统可识别全部 7 款组件并生成预览。
- 保持重置雷达 30 分钟独立同步，不因增加小组件而增加公开源请求。
- 延续重置雷达数据防回退、Full reset 只读展示、原生窗口拖动、刷新合并、CSV 导出和工作类型分析。

## 安装边界

- 系统要求：macOS 14 或更高版本。
- 架构：Apple Silicon arm64。
- 签名：ad-hoc。
- 公证：未公证，首次打开可能出现 Gatekeeper 提示。

安装包：

```text
Codex 脉动-v2.5.2-20260716-arm64.dmg
Codex 脉动-v2.5.2-20260716-arm64.dmg.sha256
```
