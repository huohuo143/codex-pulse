# Codex 脉动 2.12.25 / Build 2152

本版汇总自 2.12.8 以来的本机更新，提供 macOS Apple Silicon arm64 安装包。

- Tibo 公开动态每 10 分钟检查一次，包含发帖与回复；GPT-6 Astra / High 分析明确预告，移除重置概率预测。手动刷新、唤醒和重启共享检查间隔，七天以前的动态清理，历史月历独立保留。
- 补充公开回复线程，修复明确到账期限因父帖关系缺失而未显示的问题。成功上下文缓存；新无关动态不会让当前预告的期限消失。
- 明确的最晚到账时间换算为北京时间，在主界面、所有悬浮样式及大小号雷达小组件突出显示；按原文 PST/PDT/PT 处理时区，不猜测模糊时区，详情保留原文、链接及差异说明。
- 已确认到账后展示24小时倒计时；新预告立即覆盖到账状态与倒计时，到期等待新一轮预告。预告或经过截止时间不会被自动当成到账。
- 增大刷新时间，来源与模型均成功才显示正常标记；修复悬浮时钟重绘和桌面单色小组件文字对比度。
- 改善已有自动启动服务在升级和退出后的恢复；保留设置、历史与可回退的旧版备份。

公开源不保证收录全部 Tibo 动态。模型分析依赖本机 Codex/ChatGPT CLI 的既有登录和 GPT-6 Astra 访问权限；分析失败会明确显示状态，不以规则推断冒充模型结果。回复线程通过 Jina Reader 读取公开 X 页面，不读取 X Cookie。

主应用 macOS 13+，桌面小组件 macOS 14+。系统调度可能使小组件比主程序延后刷新。安装包采用 ad-hoc 签名，未公证；未提供新的 Intel 或 Windows 安装包。Windows 公开包仍见 v2.12.2。
