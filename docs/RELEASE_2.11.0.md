# Codex 脉动 2.11.0 / Build 2118

本版保留现有配色、四个导航、八种悬浮样式与用户设置。主应用最低 macOS 13，小组件最低 macOS 14。

## 数据与金额

- 额度、灵活余额、Full reset 各自记录来源、采样、尝试和成功时间。读取失败保留历史值并标明缓存；超过 5 分钟转为缓存，超过 30 分钟停止显示当前值。跨过官方重置时间显示“等待新周期数据”。
- 主窗口、菜单栏、悬浮框、Touch Bar、小组件和健康检查采用相同状态判断。写入快照不能延长官方数据有效期；过期额度不触发预测提醒。
- 新增 Astra，核对 Sol、Terra、Luna 的标准 API 文本价格，附来源与核验日期。金额统一为“按当前价格表折算”，显示覆盖率、部分估算和未计价模型；完全未计价时显示“暂无法估算”。复制和 CSV 使用同一口径。
- 内置价格表可由本机 JSON 导入覆盖，应用前展示差异。无效、负数、非有限数、模型或别名冲突会拒绝，旧配置保持可用。官方未公布的 GPT-5.4 Pro 缓存输入价格留空，该部分不作猜测。
- 近 7 天的金额与 Token 统一为包含今天的 7 个自然日；滚动 24 小时按真实事件时间计算。更换价格表重新估算金额，保留原始 Token 记录。
- Widget 快照升级 schema 4；新增字段可缺失，旧快照显示状态待确认。

## 到期记录与效率

- 旧固定日期 2027-07-21 迁移为历史待核实记录。设置中可编辑日期、依据与确认状态；确认与本机匿名账户标识绑定，账户变化后需要重新核实。
- 健康检查与每日备份跟随当前账户的额度历史文件，避免账户分开记录后仍检查或备份旧文件。
- 快速额度读取不遍历会话日志。文件索引结合目录事件与每 5 分钟核对，处理新增、追加、截断、替换和轮换；统计不再受最近 1,000 个文件上限限制。
- 分块解析大型日志，并迁移可复用的 v5 缓存。首次统计完成前显示“统计中”；无变化时不重新解析或分析。
- 保留选定刷新频率；窗口不可见且连续 5 分钟无会话活动时额度轮询降至 120 秒，恢复活动、唤醒和手动刷新立即检查。
- 文件与分析工作移到后台，快照合并写入并保留每分钟状态心跳。

## 界面、小组件与预测

- 首页首先展示额度、重置倒计时、24h 用量、金额完整性和 Full reset 可用次数。灵活余额、预测和雷达随后显示，详细依据、原帖翻译和模型效率默认折叠并保存展开状态。
- 主窗口适配 640×760 最小尺寸；修复余额条按钮遮挡数字和胶囊双额度文字压缩。
- 七类小组件按受影响内容刷新，普通请求至少合并 60 秒；时间线包含独立数据失效、官方重置和到期节点。仍保留启动前旧快照保护，实际执行时机由 macOS WidgetKit 调度。
- 预测先回答能否撑到重置，再解释当前速度、近期较快消耗和预测区间的影响；原有算法和阈值保持。
- 从新版本起独立归档真实生成的雷达预测、概率、证据和规则版本。设置本机结果标注入口，仅对已核实、完整结束的 24h 窗口计算 Brier score 并显示 n；未知结果不计为未发生，历史缺失预测不补造。
- 保留雷达 30 分钟抓取、5 分钟重评、证据衰减、失败退避，以及 BANKED reset 与全局硬重置的区分。
