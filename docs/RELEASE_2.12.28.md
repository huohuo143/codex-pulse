# Codex 脉动 2.12.28 / Build 2155

本轮 macOS 分发版让每位使用者读取自己的本机 Codex 账号、会话和可用模型，不依赖开发者的账号、路径或模型权限。

- 新增本机登录与模型检测；自动模式跟随当前账号默认模型，也可指定模型和推理强度。模型菜单优先列出 GPT-6 Astra 与 GPT-6.1 Sol，推理档位随模型实际能力更新。没有对应权限时明确提示调整设置。
- 新用户默认只读取 Tibo 动态，模型分析需自行开启，启用前提示额度消耗与 API Key 计费。旧用户已有分析配置会保留，包括 GPT-6 Astra / high。
- Tibo 默认使用 Codex Radar 公开源，无需 X 登录。可选 X 官网“发帖与回复”页面；通过内嵌窗口自行登录，登录态由本机 WebKit 保存，不提取其他浏览器 Cookie，也不随安装包分发。
- 公开源可能延迟或遗漏，X 只采集页面实际加载的近期内容。登录受限、空页面或解析失败显示原因，不解释为没有预告。切换来源会清除旧来源成功状态，并继续遵守十分钟检查间隔。
- 关闭模型分析后仍可查看动态与真实刷新时间；未分析不代表没有预告。本账号实际到账仍触发 24 小时倒计时。
- 内置 7—9 月可定位日期的 20 条公共历史记录及三个月原始月度统计；首次离线即可查看，未核实的日期不补造。后续仍持续读取 Tibo X 动态。
- 公共完成声明显示“Tibo确认重置/发卡”，只有当前账号本地检测到额度恢复才显示“重置已落实”；灵活额度和 Full reset 权益不由公共历史推算。
- 保留预告红色、等待绿色、落实白色，以及醒目的北京时间截止时间；新预告优先，刷新和重启不延长已有倒计时。

每位使用者需在本机 Codex 登录；仅在网页端登录 ChatGPT 不足以提供本地数据。额度和 Full reset 以账号实际返回的数据为准；本地 Token 不覆盖没有本机会话记录的活动。模型分析需要支持隔离执行参数的近期 Codex CLI，版本不兼容时提示更新。

本轮包面向 Apple Silicon Mac。主应用要求 macOS 13+，桌面小组件要求 macOS 14+。这是 ad-hoc 签名、未公证包，首次打开需由使用者按系统提示确认。桌面小组件的彩色显示仍受 macOS 小组件样式与调暗设置影响，应用不替其他使用者修改系统设置。

Windows 仍使用 [2.12.26 / Build 2153](https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.26)，本轮 macOS 新功能尚未移植。具体已验证和未验证范围见 [验证记录](VALIDATION_2.12.28.md)。
