# 2.12.3 安装与升级

从 https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.3 下载对应系统安装包，并核对 SHA256SUMS-2.12.3.txt。

Mac：下载 Codex-Pulse-v2.12.3-build2129-20261013-arm64.dmg，打开后运行“安装或更新（保留设置）.command”。主程序 macOS 13+，七款桌面小组件 macOS 14+；本次为 Apple Silicon arm64。安装器保留旧程序和配置，并提供“恢复上一版.command”。包采用 ad-hoc 签名，未公证。

Windows：使用 Codex-Pulse-Windows-2.12.3-x64-Installer.exe 升级，或直接运行 Codex-Pulse-Windows-2.12.3-x64-Portable.exe。面向 Windows 10/11 x64，无需另装 Node.js。先从托盘退出旧程序，沿用原安装位置和应用数据；旧设置、预算和历史保留。包没有商业 Authenticode 签名。回退前先保留现有数据，再恢复升级前程序和对应备份。

限流或断网时仍可使用“查看发布页”。检查按钮在提示的冷却时间后恢复可用，应用会保留上次结果。
