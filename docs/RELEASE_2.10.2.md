# Codex 脉动 2.10.2 改版说明

## build 2104：双额度同心环

- 悬浮框同时显示 7 天和 5 小时额度时，改为一个同心额度环：
  - 7 天额度使用主题色外环。
  - 5 小时额度使用橙色内环。
- 5 小时额度仍是可选项，默认关闭；只开启一种额度时自动退化为单环。
- 同心布局不再因开启 5 小时额度额外增加一个大圆，横向与竖向额度环布局都会保持紧凑。
- 圆形和胶囊悬浮样式同步使用同心环；方形、横条和徽章样式保留各自紧凑表达，并继续用不同颜色区分两种窗口。

## 桌面小组件

- “Codex 算力总览”和“Codex 额度”同步显示同心额度环。
- “设置 → macOS 桌面小组件”新增“显示 5 小时额度内环”开关，默认关闭。
- 小组件开关与悬浮框的 5 小时显示选项相互独立。
- Widget 快照升级到 schema 2；旧版 schema 1 快照缺少 5 小时字段时仍可读取，并按关闭内环处理。
- 开启内环后，小组件时间线会同时关注 7 天和 5 小时两个官方重置时间。

## 数据边界

- 5 小时与 7 天额度均来自官方窗口，不使用本地 Token 消耗反推。
- 官方没有返回 5 小时窗口时，内环数值显示 `--`。
- Widget 快照仍不包含会话正文、项目路径、账户凭据、API Key 或 Full reset 兑换 ID。
