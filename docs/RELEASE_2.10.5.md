# Codex 脉动 2.10.5 改版说明

## build 2112：电脑重启后不再把旧 Widget 快照当作实时额度

- Widget 只接受本次系统启动后写入、且最近 5 分钟内刷新的快照。
- 电脑重启后，在 APP 重新取得官方额度前显示等待刷新，不显示上次关机前的百分比。
- APP 自身重启仍可短暂保留本次开机内的最新官方快照，避免数字闪空。
- 过期状态下 Widget 每分钟重试；主 APP 写入官方值后立即恢复实时额度。
- 新增“上次系统启动快照拒绝”“本次启动近期快照接受”“当前启动过期快照拒绝”测试。

## build 2111：修复重启后的 7 天额度竞态

- 同一额度周期内固定以官方 `account/rateLimits/read` 为准，不再让 120 秒内的会话日志覆盖官方值。
- 冷启动时官方额度尚未返回则暂不发布日志百分比，避免把旧值显示成当前值。
- ChatGPT 重连或完整扫描暂时缺少官方额度时，继续保留已确认的官方结果。
- 启动阶段不再用空状态覆盖 Widget 快照。
- 新增官方值 76% 对日志值 77%、冷启动等待官方源和同周期完整扫描防覆盖回归测试。

## build 2110：修复 7 天额度回退

- 快速官方额度与完整日志扫描合并时，改为按额度样本时间和官方重置周期判断新旧。
- 完整扫描仍更新 Token 统计，但不再用旧周期的日志额度覆盖当前官方值。
- 主窗口、悬浮框、菜单栏、Touch Bar 和 Widget 继续共用同一额度结果。
- 新增“新周期 97% 不得被旧周期 59% 覆盖”、同周期防回退和新样本正常前进的回归测试。

## build 2108：按重置周期累计 Tibo 信号

- 以最近一次官方重置时间为统计边界，只综合其后的 Tibo Posts / Replies。
- 当前重置周期的状态历史保存在本机；即使相关动态被后续回复挤出公开页，评分依据也不会丢失。
- 检测到下一次官方重置完成后，旧状态与概率基线自动清零，再从新周期开始累计。
- 同类语义只计一次，跨状态综合“发布预告”“低成本 / 高供给”“明确重置措辞”和“独立 Post 权重”，估算上限 95%。
- 将 Tibo 7 月 30 日独立 Post `This week is all about intelligence too cheap to meter. Tomorrow we ship again.` 识别为组合强信号；在当前周期得到 75% 估算。
- Tibo 面板只展示参与评分的重置相关状态；普通回复、闲聊与无重置信号的状态不再显示。
- 保留原文、中文翻译、相关性标签、发布时间和 X 原帖链接。
- 不读取 X Cookie、登录态、关注列表、API Key 或其他凭据。

## 数据口径

重置百分数是 App 的本地启发式估算，不是 Tibo、OpenAI 或 Codex Radar 的官方概率。“发布预告 + 低成本 / 高供给”属于强组合信号，但不等同于官方明确承诺额度重置。
