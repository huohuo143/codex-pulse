# Windows 2.12.26 / build 2153 功能对应

| macOS 能力 | Windows 实现 |
| --- | --- |
| 公开动态预告检测 | GPT-6 Astra / High；相同分析约束和 JSON Schema；十分钟共享冷却 |
| 回复线程和明确截止时间 | Jina 公开线程 URL 与原文校验；程序换算北京时间；时区歧义保留 |
| 2.12.26 本账号实际重置 | 账号隔离的周额度历史，同时检测回升与新周期；相同数值门槛 |
| 到账展示 | 原始到账样本起 24 小时；新预告优先；刷新状态独立；跨重启延续 |
| 历史月历 | 独立离线缓存、33 条相同历史补录、来源角色与日期精度、月度总数单列 |
| 灵活额度记录 | 批次编辑、数量精度、保存锁、草稿保留、记录保护与显式恢复 |
| 记录安全 | 大小受限的普通文件、未来版本保护、外部修改检测、上一份有效记录 |
| 新版日志格式 | JSONL / Zstd、归档目录、会话身份去重、流式读取、不完整帧拒绝提交 |
| 菜单栏、悬浮框、小组件 | Windows 托盘、八类悬浮框、七类桌面卡片 |
| 系统集成 | Windows 登录启动、Codex 进程监测、Windows 通知、可选 OneDrive 聚合同步 |
| 升级备份 | 首次启动新版本前备份关键数据并校验；旧安装包保留用于恢复程序 |

本次提供 x64 包。Windows 桌面卡片为 Electron 独立窗口，系统调度与 macOS WidgetKit 不同。macOS 专用的 Touch Bar、沙盒签名和启动服务不属于 Windows 的系统接口。既有 Windows 自动化与诊断保持原有操作方式；不宣称逐项运行了 macOS 的 Swift 测试。
