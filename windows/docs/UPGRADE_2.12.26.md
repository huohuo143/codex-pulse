1. 退出旧版 Codex 脉动，从托盘选择退出。
2. 运行同目录中的 Installer 安装包，或双击 Portable 免安装包。
3. 确认窗口版本为 v2.12.26、build 2153。普通主窗口、托盘、悬浮框和桌面卡片均可继续使用。
4. 新版先备份既有关键数据，再保存设置。备份位于原数据目录 version-backups，附带逐文件 SHA-256 清单；旧安装包继续保留。
