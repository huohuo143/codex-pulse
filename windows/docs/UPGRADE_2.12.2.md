# Windows 2.12.2 更新说明

与 macOS 2.12.2 同步本轮改进，保留 2.12.1 圆环文字布局修复。

- 预算仅接受正整数，可输入英文千位逗号；空值、0、负数、小数和指数不会误保存/删除。删除使用独立按钮。
- 写入成功后才更新预算状态，失败保留原输入；后台刷新不覆盖草稿，保存期间阻止重复提交。
- 已被系统接受的提醒即使回执晚于账户切换，仍记入原账户；写入失败保留内存回执并在巡检时重试。
- 每日备份按文件保存并以 SHA-256 完成清单验证；同日新账户/新记录补齐，空备份不报完成，失败重试，旧版备份文件保留。
- 会话文件变更按路径更新索引；目录事件和未知事件回退扫描。
- 刷新失败释放按钮，成功后清除旧错误；刷新进行中不被中间统计更新覆盖。成功/错误提示区分。
- file URL 的中文项目名和路径只在显示时解码一次，项目 ID 和已有预算关联不变。

本轮运行验证和 Windows 原生验收范围以 VALIDATION_2.12.2.md 为准。安装包见 https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.2 。
