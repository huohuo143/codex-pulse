# Codex 脉动 Windows 2.12.2

面向 Windows 10/11 x64 的 Codex 状态面板、独立悬浮框与七类桌面卡片。界面和功能继续对齐macOS 2.12.2，并保留 2.12.1 环形布局修复；验证状态见 [验收报告](docs/VALIDATION_2.12.2.md)。

> 2.12.2 已完成 Windows 10 x64 原生测试、打包、备份升级和已安装界面检查。下载 [Windows 安装包](https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.2)，查看 [验证范围](docs/VALIDATION_2.12.2.md)。

## 安装与使用

在 [v2.12.2 发布页](https://github.com/huohuo143/codex-pulse/releases/tag/v2.12.2) 下载；本地构建的交付文件位于 dist（本地仍使用中文“安装版／免安装”文件名）：

- Codex-Pulse-Windows-2.12.2-x64-Installer.exe：安装向导、桌面与开始菜单快捷方式。
- Codex-Pulse-Windows-2.12.2-x64-Portable.exe：双击运行，无需安装 Node.js。
- SHA256SUMS-2.12.2.txt：文件校验值。旧 2.12.1 产物保留。

需要本机已安装并登录 Codex 桌面版或 CLI。首次打开显示主窗口；在设置中开启悬浮框、桌面卡片和通知。关闭窗口后继续托盘运行，从托盘选择“退出 Codex 脉动”才会结束全部窗口与后台任务。

本版本没有商业 Authenticode 签名。

## 新版功能

- 2.12.2：严格预算输入、保存失败保留草稿；提醒晚回执按原账户记账；SHA-256 备份验收与单文件增量扫描；刷新/错误状态恢复；中文项目显示。
- 2.12.1：倒计时移到圆环外，中央字体按尺寸调整，单双环、迷你浮窗及桌面额度卡片均预留安全间距；未开启的 5 小时文字正确隐藏。
- Mac 风格的分段导航、图标工具栏、双额度摘要、独立灵活额度与预测卡片，保留 Windows 最小化、最大化和关闭到托盘。
- 趋势页增加当前账户官方额度历史，支持 24 小时/7 天/30 天、悬停和键盘查看、原始样本 CSV；周期变化、额度上调或超过 90 分钟缺少采样时断线。
- 用量 CSV 增加完整 UTC 小时、本机逐日、设备汇总和设备逐日分区；同一设备取最新快照，文本按公式安全方式导出。
- 通知仅在系统返回成功事件后记账，失败至少等待 60 秒后重试，账户切换隔离旧异步结果。
- 灵活额度支持多批次发放/到期记录，区分已核实日期与个人推算；旧单笔记录继续保留。额度环每分钟更新“距重置 X天 X小时”。
- 雷达显示公开源最新动态和挑战摘要，摘要不计入重置承诺；短暂故障同次最多尝试 3 次，主请求最多 30 秒，附属来源最多 6 秒，保存退避和 Retry-After 状态供重启恢复。
- 7 天额度外环与可选 5 小时内环、灵活余额、Full reset 只读权益。
- 官方数据分别记录采样与成功时间；5 分钟后标记缓存，30 分钟后停止显示当前值，跨重置时间等待新周期。
- 额度预测与三套提醒阈值：标准 30/15/5%、提前 50/30/15%、紧急 15/5%；支持预测高风险和权益到期提醒。
- 滚动 24h、30 天趋势、多设备分色堆叠、14 天同期分析、稳健异常检测、项目月度 Token 预算。
- 本地增量日志统计：后台线程、分块读取、文件监听与定期核对，取消 1,000 文件限制。
- API 等价金额、计价覆盖率与未计价模型；支持导入价格表并预览差异。内置价格表沿用基线核验日期，设置中的本机覆盖表可更新价格。
- Codex Radar / Tibo 公开动态每 30 分钟读取，5 分钟本地重评，证据衰减，90 分钟未成功读取则停止显示概率。BANKED reset 不计入全局硬重置。
- 真实雷达预测归档、本机结果标注、已核实样本的 Brier score 与样本数。
- 四个页面、八种悬浮样式、三套外观、六套主题色、系统/白天/夜晚模式。
- 总览、额度、雷达、Full reset、Token 汇总、趋势、项目与用途七类桌面卡片，可分别开关、移动、缩放和置顶。
- 七项健康检查、受控重新检查、每日关键数据备份、可选每日聚合摘要、版本检查和脱敏诊断导出。

## 旧版升级与数据位置

沿用安装标识 dev.codex.balance-dashboard.codex.windows。优先使用已有的 %APPDATA%\Codex算力码表 或 %APPDATA%\suanli-dashboard-windows 数据目录，避免改名造成设置丢失。

首次迁移前，在数据目录创建 migration-backup-时间戳，保留旧 settings.json 和可读的 v4/v5 缓存。缓存备份移除未完成的对话末行，并回退读取位置；损坏缓存留下重建标记，启动后从原始日志重建。主题、透明度、刷新频率与同步开关保留；原紧凑模式转为独立悬浮框开关。早期 v5 缓存曾跳过不带额度的 Token 事件，因此会重建一次；已带新版解析标记的 v5 缓存直接复用。

每日备份位于数据目录 backups，仅保留最近七份。账户额度历史和提醒记录使用匿名账户标识隔离。更换账户后，灵活余额到期日期需要重新核实。

如需回退：退出应用并保留当前数据副本，再恢复升级前程序及对应备份。早期迁移场景可使用 migration-backup 中的设置与有效缓存；只有重建标记时由旧版重新解析日志。保留备份原件。

## 数据来源与隐私

原始会话仅在本机解析。价格与金额是标准文本 API 等价估算，不是 ChatGPT/Codex 订阅账单；reasoning 已包含在 output 中，不重复计费。未知模型及未知缓存单价不猜价。

读取本机 CODEX_HOME/sessions、用户 .codex/sessions、.codex/browser/sessions，以及既有 AppData Codex 会话目录。官方额度优先来自 codex app-server；Full reset 仅执行读取。

OneDrive 沿用“算力码表/设备统计”目录，只写设备信息、小时/日/月/模型及聚合 Token 数字，兼容 schema 2/3/4。未配置 OneDrive 时正常使用本机统计。

网络请求用于 Codex 官方账户读取、chatgpt.com 的 Full reset 只读接口、codexradar.com 公开页面与重置周期、Frankfurter 汇率、GitHub Releases 更新检测。不会上传对话内容、凭据或完整账户 ID。雷达不读取 X Cookie。

## 开发与构建

需要 Windows x64、Node.js 22.12+ 和 npm。Electron 固定 43.1.0，electron-builder 固定 26.15.3。

~~~powershell
npm ci
npm test
npm start
npm run dist:win
~~~

网络共享目录建议运行 tools/build-windows.ps1，在本机临时目录构建后将交付文件复制回 dist。该脚本保留临时构建目录供排错，不修改用户数据。

测试隔离环境变量：CODEX_PULSE_SUPPORT_DIR 指定独立数据目录；CODEX_PULSE_SESSION_ROOT 指定测试会话；CODEX_PULSE_OFFLINE=1 禁止测试实例联网和同步；CODEX_PULSE_ACCEPTANCE=1 每分钟写脱敏运行验收记录。正式使用无需设置这些变量。

详见 [功能对齐](docs/v2.12.2-feature-parity.md)、[升级说明](docs/UPGRADE_2.12.2.md) 和 [验收报告](docs/VALIDATION_2.12.2.md)。
