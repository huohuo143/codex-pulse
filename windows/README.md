# Codex 脉动 Windows 2.12.29 · build 2157

面向 Windows 10/11 x64 的主面板、系统托盘、独立悬浮框和七类桌面卡片。基于 Windows 2.12.26 适配 macOS 2.12.29：可选本机模型、隔离的 X 登录、公开线程定期复查、重置周期边界与三色状态。

## 下载与使用

交付文件在 `dist`：

- `Codex-Pulse-Windows-2.12.29-build2157-x64-Installer.exe`：安装向导，保留原应用标识、设置与历史。
- `Codex-Pulse-Windows-2.12.29-build2157-x64-Portable.exe`：免安装版，双击运行，无需另装 Node.js。
- `SHA256SUMS-2.12.29.txt`：SHA-256 校验值。

需要本机已安装并登录 Codex。预告分析另需既有账号可用的 GPT-6 Astra 模型权限；没有权限、超时或断网时会显示实际失败状态。离线日历和本地统计仍可使用。关闭主窗口后继续在托盘运行，从托盘选择退出才结束后台任务。

## 本版适配

- 每 10 分钟读取公开源收录的 Tibo 发帖与回复，使用本机 Codex 的 用户选择的本机可用模型 分析明确预告；主界面、全部悬浮样式和桌面卡片取消概率评分。
- 校验公开回复线程、原帖依据和逐字引用，明确的截止时间由程序换算为北京时间；PST、PDT 与 PT 分别处理，含糊或重复的夏令时时刻不猜测。
- 当前账户官方周额度同时回升、周周期提前重新开始时确认到账。普通数值修正、自然到期、短周期变化、未来样本和长时间缺测不算本次重置。
- “已完成重置”和 24 小时展示倒计时以首次检测到账的历史采样为起点，刷新、重启和较晚公开确认不会延长；新预告优先。到账事实和来源／模型刷新状态分别展示。
- 独立重置日历，固定北京时间、周一至周日、月份切换、硬重置／重置卡筛选、同日多事件和来源详情。随应用附带 33 条公开历史记录；来源月度总数单列，离线资料不冒充联网成功。快捷键 Ctrl+4。
- 灵活额度批次支持编辑、完整数量精度、严格千位分组、保存中锁定表单、失败与账号变化后保留草稿。
- 额度历史、项目预算、单笔和分批额度记录使用受保护文件，异常或不支持版本停止写入。提供重新读取、恢复上次有效记录和记录文件夹入口，恢复前保留损坏原件。
- 同时统计普通和压缩的 `.jsonl` / `.jsonl.zst` 日志及 `archived_sessions`。按会话去重，先验证完整压缩帧，再流式解压；截断、损坏或读取期间变化的压缩记录不覆盖已知统计，并自动重试。
- 每日备份进行普通文件、清单版本、外部修改和 SHA-256 检查，包含有效记录备份、雷达与独立日历。首次运行新版本前另创建带校验清单的关键数据升级备份。

保留双额度环、额度预测与提醒、Token 趋势、项目预算、API 等价金额、可选 OneDrive 聚合统计同步、七类桌面卡片、八种悬浮样式、主题、更新检查和脱敏诊断。

## 升级与回退

沿用 `dev.codex.balance-dashboard.codex.windows`。优先使用原有 `%APPDATA%\Codex算力码表` 或 `%APPDATA%\suanli-dashboard-windows`。新版本首次运行会将选定的设置和记录备份到数据目录 `version-backups`，不复制账号授权或原始会话。

旧安装包保留在 `dist`。回退前退出全部本应用窗口并保留当前数据副本，重新安装旧版，再按需要恢复升级备份中的设置与记录。升级备份包含数据；旧程序通过保留的旧安装包恢复。旧解析缓存会重建一次以取得会话身份，不删除原始日志。

## Windows 适配范围

SwiftUI、WidgetKit、Touch Bar、iCloud 与 macOS 启动服务由 Electron 窗口、Windows 系统托盘、桌面卡片、OneDrive 和登录启动实现对应能力。Windows 桌面卡片是独立应用窗口。现有 Windows 版的设置、通知和自动化继续保留；macOS 专用系统服务代码不直接移植。

## 数据来源与隐私

本地会话在后台线程读取；同步仅含聚合数字。API 等价金额不是订阅账单，未知模型不猜价。模型分析只提交最近七天公开帖子及经验证的公开线程，禁用模型工具、文件修改、联网搜索和子代理；不提交本地会话或凭据，不读取 X Cookie，不自动消耗 Full reset。

网络来源：Codex 官方账号只读接口、Codex Radar、Jina Reader 公开线程、Frankfurter 和 GitHub 更新接口。来源可能不完整；本账号到账不代表所有账号到账。

## 开发

使用 Windows x64、Node.js 24+ 和 npm。Electron 固定 43.1.0，electron-builder 固定 26.15.3。压缩解码由随应用附带的 Electron/Node 提供。

~~~powershell
npm ci
npm test
npm start
npm run dist:win
~~~

网络共享或中文目录建议运行 `tools/build-windows.ps1`，在本机临时目录构建后复制回 `dist`。仅有 Node 的环境可用 `-NpmCli` 指定 npm-cli.js。

测试隔离：`CODEX_PULSE_SUPPORT_DIR` 使用独立配置目录；`CODEX_PULSE_SESSION_ROOT` 指定测试日志；`CODEX_PULSE_OFFLINE=1` 关闭测试实例的自动网络／同步；正式使用无需设置。
